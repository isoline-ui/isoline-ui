# Security policy

## Supported versions

| Version                        | Supported |
| ------------------------------ | --------- |
| 2.0.x (development source)     | Yes       |
| 1.x and earlier alpha archives | No        |

## Reporting a vulnerability

Do not open a public issue. Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/isoline-ui/isoline-ui/security/advisories/new).

Include the affected version or commit, the platform (Android/iOS, Expo and React
Native versions) and steps to reproduce. You should hear back within a few days.
Once a fix is ready, it is released and credited in the changelog unless you ask
to stay anonymous.

---

## Ein Release auswählen

Öffne [GitHub Releases](https://github.com/isoline-ui/isoline-ui/releases) und lies die Hinweise zur gewünschten Version. Verwende die `.tgz`-Paketdateien, nicht die automatisch erzeugte ZIP des gesamten Repositorys.

Für das UI-Paket allein aktualisierst du dessen Archiv-URL. Nutzt du die native Darstellung, aktualisiere **beide Pakete gemeinsam** auf dieselbe Version. Die Peer-Abhängigkeit des nativen Pakets erwartet die passende UI-Version.

## Deine App aktualisieren

1. Installiere die neue Archiv-URL beziehungsweise beide URLs mit deinem Paketmanager.
2. Committe `package.json` und die Lockdatei.
3. Prüfe die Release-Hinweise auf geänderte Eigenschaften und native Abhängigkeiten.
4. Führe den Typecheck deiner App aus und probiere die verwendeten Bildschirme aus.
5. Baue die native App neu, wenn sich nativer Code oder native Abhängigkeiten geändert haben.

Ersetze kein altes `.tgz`-Archiv unter derselben URL oder Versionsnummer. Unveränderliche Release-URLs sorgen dafür, dass `npm ci` deine Installation reproduzieren kann.

## Ein lokales Archiv verwenden

```sh
npm install ./vendor/isoline-ui-react-native-0.1.0-alpha.1.tgz
```

Stelle diese Datei deinem Team und CI zur Verfügung. Committe sie bei dieser Variante zusammen mit der App. Über mehrere Apps hinweg ist die Release-URL meistens einfacher.

## Falls ein Update Probleme macht

Stelle die vorherige Archiv-URL und die Lockdatei wieder her. Hat sich der native Code geändert, brauchst du auch eine dazu passende native App-Version oder einen erneuten nativen Build. Siehe [Development-Builds](/de/docs/native/development-builds).

title: 'Updating Isoline'
description: 'Update the npm packages without losing a reproducible installation.'
---

## Choose a version

Check the [changelog](https://github.com/isoline-ui/isoline-ui/blob/main/CHANGELOG.md) and the versions on npm for [`@isoline-ui/react-native`](https://www.npmjs.com/package/@isoline-ui/react-native) and [`@isoline-ui/native`](https://www.npmjs.com/package/@isoline-ui/native). Read the notes for every version between yours and the target.

If you use native appearance, update **both packages together** to the same version. The native package's peer dependency expects the matching UI version.

## Update your app

1. Install the new version, for example `npm install @isoline-ui/react-native@latest @isoline-ui/native@latest`.
2. Commit `package.json` and your lockfile.
3. Check the changelog for changed props and native dependencies.
4. Run your app's typecheck and try the screens you use.
5. Rebuild the native app if native code or native dependencies changed.

## If an update goes wrong

Install the previous versions again and restore your lockfile. When the installed native code changed, restore or rebuild a native app that matches the JavaScript version too. See [Development builds](/en/docs/native/development-builds).

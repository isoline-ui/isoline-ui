Die Vorschau legt die Glasfläche über kontrastreiche Farbbänder und Schrift. Vergleiche mit „Solide Darstellung“ dieselbe Szene ohne Glas und wechsle zwischen „Regulär“ und „Klar“. Das Beispiel verwendet ausdrücklich `glassStyle="clear"`; der Standard bleibt `regular`. Unter Android und bei einer notwendigen soliden Alternative bleibt die Fläche undurchsichtig.

## Eine Fläche ergänzen

Rendere `MaterialSurface` nach der [nativen Installation](/de/docs/native/overview) innerhalb von `IsolineProvider`:

```tsx title="FloatingActions.tsx"
import { MaterialSurface } from '@isoline-ui/native';
import { Button, Text, useThemeColors } from '@isoline-ui/react-native';
import { View } from 'react-native';

export function FloatingActions() {
  const colors = useThemeColors();
  return (
    <View
      style={{
        height: 240,
        borderRadius: 24,
        overflow: 'hidden',
        backgroundColor: colors.primaryContainer,
      }}
    >
      <View
        pointerEvents="none"
        style={{
          position: 'absolute',
          left: -24,
          right: -24,
          top: 64,
          height: 104,
          backgroundColor: colors.primary,
          transform: [{ rotate: '-16deg' }],
        }}
      />
      <View
        pointerEvents="none"
        style={{
          position: 'absolute',
          left: '55%',
          right: -24,
          top: 0,
          bottom: 0,
          backgroundColor: colors.tertiary,
        }}
      />
      <MaterialSurface
        glassStyle="clear"
        style={{
          position: 'absolute',
          left: 16,
          right: 16,
          bottom: 24,
          borderRadius: 28,
          padding: 16,
        }}
      >
        <View
          style={{
            flexDirection: 'row',
            alignItems: 'center',
            justifyContent: 'space-between',
            gap: 12,
          }}
        >
          <Text variant="subject" style={{ flex: 1 }}>
            Deine Sammlung
          </Text>
          <Button label="Neu" size="s" onPress={() => {}} />
        </View>
      </MaterialSurface>
    </View>
  );
}
```

Platziere die Fläche über abwechslungsreichem Inhalt, etwa einer scrollenden Liste oder Bildern, wenn das Material sichtbar werden soll. Auf einem gleichmäßigen Hintergrund fällt der Effekt von Natur aus weniger auf. Die Vorschau oben nutzt die echten Komponenten mit React Native Web und CSS-Glas; die iOS-App nutzt Expos native Glas-View.

## Passende Stellen auswählen

Beginne mit einer kleinen schwebenden Werkzeugleiste oder einer ergänzenden Navigationsfläche. Halte größere Lese- und Formularflächen gut lesbar. `MaterialSurface` zeichnet eine View mit Materialhintergrund. Es erstellt keine Navigationsleiste, Tab-Bar und keinen nativen Button für dich.

`interactive` aktiviert die native Materialinteraktion. Ergänze einen `Button`, `IconButton` oder eine eigene barrierefreie Aktion, damit beim Drücken etwas passiert.

## Alternative Darstellung

Natives Glas wird auf **iOS 26+** verwendet, wenn die benötigten APIs verfügbar sind und die App die Liquid-Glass-Darstellung unterstützt. Auf älteren iOS-Versionen, unter Android und bei reduzierter Transparenz zeigt die Komponente eine undurchsichtige Theme-Fläche. Auch `material="glass"` berücksichtigt diese Prüfungen. `material="solid"` fordert immer die undurchsichtige Alternative an.

Die Glasdarstellung folgt dem hellen oder dunklen Isoline-Theme. Teste beide Varianten und die reduzierte Transparenz in den iOS-Bedienungshilfen.

## Hinweise zur Gestaltung

Verwende `style` für Innenabstand, Layout und Eckenradius. Ein undurchsichtiger Hintergrund kann das Material verdecken. Vermeide reduzierte Deckkraft auf dem Glas oder seinen übergeordneten Views, auch durch Press-Opacity-Wrapper. Setze stattdessen bedienbare Elemente hinein. Blende bei Animationen nicht die gesamte Fläche wie eine normale undurchsichtige View aus.

## Eigenschaften

| Eigenschaft     | Typ / Standard                             | Verwendung                                                                      |
| --------------- | ------------------------------------------ | ------------------------------------------------------------------------------- |
| `material`      | `auto / glass / solid · default: auto`     | Verwende Glas, sofern verfügbar, oder ausdrücklich eine undurchsichtige Fläche. |
| `glassStyle`    | `regular / clear · default: regular`       | Wähle die native Glasdarstellung.                                               |
| `tintColor`     | `string`                                   | Optionale Tönung für das native Glas.                                           |
| `interactive`   | `boolean · default: false`                 | Aktiviere die native Materialinteraktion. Das ergänzt keine Aktionsbehandlung.  |
| `fallbackColor` | `string · default: theme.surfaceContainer` | Hintergrund der undurchsichtigen Alternative.                                   |
| `View props`    | `React Native ViewProps`                   | Setze Layout, Radius, Innenabstand, Bedienungshilfen und Inhalt.                |

Verwende ein Bottom Sheet für eine kurze Aufgabe oder mehrere Auswahlmöglichkeiten, die beim aktuellen Bildschirm bleiben sollen. Du steuerst, ob es geöffnet ist.

Die Rundungen passen sich an iOS oder Android an. Eine sichtbare Schließen-Aktion funktioniert mit Touch, Tastatur und Hilfstechnologien; der Griff unterstützt zusätzlich Ziehen.

## Ein Sheet öffnen und schließen

```tsx
import { useState } from 'react';
import { View } from 'react-native';
import { BottomSheet, Button, Text } from '@isoline-ui/react-native';
export function SheetExample() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Button label="Show details" onPress={() => setOpen(true)} />
      <BottomSheet visible={open} onClose={() => setOpen(false)}>
        <View className="gap-4">
          <Text variant="heading">A little more detail</Text>
          <Text>Keep the next step clear and close at hand.</Text>
          <Button label="Done" onPress={() => setOpen(false)} />
        </View>
      </BottomSheet>
    </>
  );
}
```

## Scrollbarer Inhalt

Das Sheet fügt nicht automatisch eine Scroll-View hinzu. Lege für längere Inhalte eine begrenzte `ScrollView` oder Liste hinein und teste sie mit geöffneter Tastatur und großer Schrift. Die Geste zum Schließen sitzt am Griff, damit scrollbare Inhalte unabhängig bedienbar bleiben.

## Schließen und Tastatur

`onClose` behandelt den Hintergrund, Android-Zurück, barrierefreies Schließen und die Schließgeste. Aktualisiere in diesem Callback immer deinen `visible`-Zustand. Ein Formular kann über `onShow` ein Eingabefeld fokussieren. Die Anpassung an die iOS-Tastatur ist eingebaut.

Gemeinsame Overlays nutzen die `popover`-Fläche. Der Standard-Hintergrund eines TextField-Labels passt daher dazu. Für eine Aktionsliste gibt es [MenuSheet](/de/docs/components/menu-sheet), für eine kurze Bestätigung [Dialog](/de/docs/components/dialog).

## Eigenschaften

| Eigenschaft | Typ / Standard                  | Verwendung                                                                                     |
| ----------- | ------------------------------- | ---------------------------------------------------------------------------------------------- |
| `visible`   | `boolean · required`            | Steuere, ob das Sheet sichtbar ist.                                                            |
| `onClose`   | `() => void · required`         | Setze deinen Öffnungszustand auf false.                                                        |
| `onShow`    | `() => void`                    | Wird nach Erscheinen des nativen Modals ausgeführt, zum Beispiel zum Fokussieren eines Feldes. |
| `maxHeight` | `DimensionValue · default: 90%` | Begrenze die Panelhöhe.                                                                        |
| `children`  | `ReactNode · required`          | Ergänze Inhalt und Aktionen.                                                                   |

## Lange Listen und Texteingabe

Nutze [SheetScrollView und PanelSheet](/de/docs/components/advanced-sheets) für abgestimmtes Scrollen und Formulare mit Tastaturanpassung im Screen. Standardmäßig beginnt die Geste am Griff. `theme.sheetGesture = "panel"` erlaubt das Ziehen am ganzen Panel mit Scroll-Koordination; das cyan-Preset wählt diese Option. Das Modal bleibt bis zum Ende der Schließanimation eingebunden und behält dabei seinen vorherigen Inhalt.

## Materialoptionen

Die passenden Controls und Overlay-Flächen unterstützen den gemeinsamen Materialvertrag einschließlich `glassStyle`, `tintColor`, `fallbackColor` und `interactive`. Siehe [Materialien und Liquid Glass](/de/docs/foundations/materials) für Standards, Adapter, Zustände und Alternativen.

Ein einfaches Eingabefeld mit Beschriftung, Hinweis, Fehler und optionaler Passwortsichtbarkeit.

## Verwendung und Zustände

Input bietet eine einfache dauerhaft sichtbare Beschriftung, TextField eine plattformabhängige Darstellung. Beide nehmen TextInput-Props und Refs an. Das Beispiel zeigt Hinweis, Validierung und ein nicht bearbeitbares Feld. Fehler ersetzen Hinweise; `editable={false}` sperrt die Eingabe. Tastatur, Autofill und Großschreibung passend zu den Daten setzen. `className` gestaltet TextInput, nicht die äußere Gruppe.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="InputExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function InputExample({ de = false }: StoryProps) {
  const [name, setName] = React.useState('');
  const [submitted, setSubmitted] = React.useState(false);
  return (
    <View style={{ gap: 16 }}>
      <UI.Input
        label={de ? 'Name' : 'Name'}
        hint={de ? 'Dein öffentlicher Name' : 'Your public name'}
        value={name}
        onChangeText={setName}
        error={submitted && !name.trim() ? (de ? 'Name fehlt.' : 'Enter your name.') : null}
        autoCapitalize="words"
      />
      <UI.Input
        label={de ? 'Nicht bearbeitbar' : 'Read only'}
        value="Isoline"
        editable={false}
      />
      <UI.Button label={de ? 'Prüfen' : 'Validate'} onPress={() => setSubmitted(true)} />
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <InputExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `Input`.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

Maskierung, Anzeigen/Verbergen und Passwortmanager-Hinweise: [Passwortfelder](/de/docs/components/password-input).

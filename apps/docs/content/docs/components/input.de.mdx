Ein einfaches Eingabefeld mit Beschriftung, Hinweis, Fehler und optionaler Passwortsichtbarkeit.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="InputExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function LayoutExample({ de = false }: StoryProps) {
  const [expanded, setExpanded] = React.useState(false),
    [value, setValue] = React.useState('');
  const t = (en: string, german: string) => (de ? german : en);
  return (
    <UI.KeyboardInsetView>
      <View style={{ gap: 16 }}>
        <View>
          <UI.Text>{t('First row', 'Erste Zeile')}</UI.Text>
          <UI.RowGap />
          <UI.Text>{t('Second row', 'Zweite Zeile')}</UI.Text>
        </View>
        <UI.Button
          label={t('Expand details', 'Details aufklappen')}
          onPress={() => setExpanded((value) => !value)}
        />
        <UI.ExpandIndicator expanded={expanded} />
        <UI.Badge label="3" />
        <UI.Input
          accessibilityLabel={t('Example input', 'Beispieleingabe')}
          value={value}
          onChangeText={setValue}
        />
        <UI.EmptyState
          icon={UI.BackIcon}
          shape="cookie"
          title={t('Nothing here yet', 'Noch keine Einträge')}
          body={t(
            'An empty state keeps the next action clear.',
            'Ein leerer Zustand zeigt die nächste Aktion.',
          )}
        />
      </View>
    </UI.KeyboardInsetView>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <LayoutExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `Input`.

Wichtige Props: `value`, `onChangeText`, `label`, `hint`, `error`, `secureTextEntry`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

Maskierung, Anzeigen/Verbergen und Passwortmanager-Hinweise: [Passwortfelder](/de/docs/components/password-input).

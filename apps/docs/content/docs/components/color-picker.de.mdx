Eine barrierefreie Palette mit ausgewählten und deaktivierten Farben sowie einer Sheet-Darstellung. Die App liefert Farben und Namen.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="ColorswatchesExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function ColorPickerExample({ de = false }: StoryProps) {
  const [color, setColor] = React.useState<string | null>('#7c4ab1');
  const [open, setOpen] = React.useState(false);
  const t = (en: string, german: string) => (de ? german : en);
  const swatches = [
    { value: '#7c4ab1', label: t('Violet', 'Violett') },
    { value: '#008577', label: t('Teal', 'Türkis') },
    { value: '#dc8045', label: t('Orange', 'Orange') },
    {
      value: '#777777',
      label: t('Unavailable color', 'Nicht verfügbare Farbe'),
      disabled: true,
    },
  ];
  return (
    <View style={{ gap: 20 }}>
      <UI.ColorSwatchPicker
        value={color}
        onChange={setColor}
        swatches={swatches}
        accessibilityLabel={t('Colors', 'Farben')}
      />
      <UI.Button
        label={t('Open color picker', 'Farbauswahl öffnen')}
        onPress={() => setOpen(true)}
      />
      <UI.Text accessibilityLiveRegion="polite">{color}</UI.Text>
      <UI.ColorPickerSheet
        visible={open}
        onClose={() => setOpen(false)}
        title={t('Choose color', 'Farbe wählen')}
        value={color}
        onChange={setColor}
        swatches={swatches}
        accessibilityLabel={t('Sheet colors', 'Farben im Sheet')}
      />
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <ColorPickerExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `ColorSwatchPicker`, `ColorPickerSheet`.

Wichtige Props: `value`, `onChange`, `swatches`, `accessibilityLabel`, `visible`, `onClose`, `title`, `material`, `glassStyle`, `tintColor`, `fallbackColor`, `interactive`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

Glas, solide Alternativen und den Hintergrund vergleichen: [Picker und schwebende Materialien](/de/docs/components/overlay-materials).

Auswahl, Abschnittsüberschriften und Nach-oben-Aktion mit Beschriftungen und Callbacks aus der App.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="ListcontrolsExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function ListControlsExample({ de = false }: StoryProps) {
  const [count, setCount] = React.useState(2),
    [status, setStatus] = React.useState('');
  const t = (en: string, german: string) => (de ? german : en);
  return (
    <View style={{ gap: 16 }}>
      <UI.SelectionHeader
        count={count}
        countLabel={t(`${count} selected`, `${count} ausgewählt`)}
        allSelected={count === 4}
        onClear={() => setCount(0)}
        onToggleAll={() => setCount((value) => (value === 4 ? 0 : 4))}
        clearLabel={t('Clear selection', 'Auswahl aufheben')}
        selectAllLabel={t('Select all', 'Alle auswählen')}
        deselectAllLabel={t('Select none', 'Keine auswählen')}
      />
      <UI.ListSectionHeader
        title={t('Recent items', 'Letzte Einträge')}
        first
        trailing={<UI.Badge label="4" />}
      />
      <UI.Text>
        {t('The app supplies the list and selection.', 'Die App liefert Liste und Auswahl.')}
      </UI.Text>
      <UI.JumpToTopPill
        label={t('Back to top', 'Nach oben')}
        count={3}
        onPress={() => setStatus(t('Top requested', 'Nach oben angefordert'))}
      />
      <UI.Text accessibilityLiveRegion="polite">{status}</UI.Text>
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <ListControlsExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `SelectionHeader`, `ListSectionHeader`, `JumpToTopPill`.

Wichtige Props: `count`, `countLabel`, `allSelected`, `onClear`, `onToggleAll`, `title`, `label`, `onPress`, `material`, `glassStyle`, `tintColor`, `fallbackColor`, `interactive`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

Glas, solide Alternativen und den Hintergrund vergleichen: [Picker und schwebende Materialien](/de/docs/components/overlay-materials).

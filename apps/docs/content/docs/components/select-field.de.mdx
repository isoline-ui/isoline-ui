Verwende `SelectField` für eine Einstellung, deren Optionen mehr Platz als eine Button-Gruppe benötigen. Das Feld öffnet ein verankertes Popover und schließt sie nach der Auswahl.

## Eine typsichere Auswahl

```tsx
import { useState } from 'react';
import { SelectField } from '@isoline-ui/react-native';
type SortOrder = 'newest' | 'oldest' | 'name';
export function SortPicker() {
  const [order, setOrder] = useState<SortOrder>('newest');
  return (
    <SelectField<SortOrder>
      value={order}
      onChange={setOrder}
      accessibilityLabel="Sort order"
      options={[
        { id: 'newest', label: 'Newest first' },
        { id: 'oldest', label: 'Oldest first' },
        { id: 'name', label: 'By name' },
      ]}
    />
  );
}
```

## Einen gültigen aktuellen Wert verwenden

Wähle eine anfängliche ID, die in `options` vorkommt. Lädt deine App die Optionen asynchron, zeige die Auswahl erst mit einem gültigen Wert an oder verwende einen getrennten Ladezustand.

SelectField ist eine kurze Einfachauswahl in einem verankerten Popover. `value={null}` zeigt `placeholder`. `label`, `hint` und `error` bilden den Formularzustand ab; Fehler haben Vorrang vor Hinweisen. `disabled` verhindert Öffnen und schließt ein bereits offenes Menü. Optionen können einzeln deaktiviert sein. Für lange oder asynchrone Listen verwende [Combobox](/de/docs/components/combobox).

## Eigenschaften

| Eigenschaft          | Typ / Standard                  | Verwendung                                        |
| -------------------- | ------------------------------- | ------------------------------------------------- |
| `value`              | `T oder null · erforderlich`   | ID der ausgewählten Option.                       |
| `options`            | `SelectOption<T>[] · required`  | Optionen mit eindeutiger id und sichtbarem label. |
| `onChange`           | `(value: T) => void · required` | Speichere die ausgewählte ID.                     |
| `accessibilityLabel` | `string · required`             | Name der Einstellung, die diese Auswahl ändert.   |

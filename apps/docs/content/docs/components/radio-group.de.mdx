Eine sichtbare Option mit Tastatur und Screenreader auswählen.

## Verwendung und Zustände

Für eine sichtbare Einfachauswahl. `RadioItem` mit eindeutigen Werten direkt in `RadioGroup` platzieren; Fragmente und verschachtelte Gruppen werden nicht registriert. `null` bedeutet keine Auswahl. Pfeiltasten überspringen deaktivierte Einträge, Home/End wählen den ersten/letzten verfügbaren Eintrag. Eine Gruppenbeschriftung angeben. Für unabhängige Mehrfachauswahl Checkbox verwenden.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="RadiogroupExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function RadioExample({ de = false }: StoryProps) {
  const [value, setValue] = React.useState<string | null>('standard');
  return (
    <UI.RadioGroup
      value={value}
      onValueChange={setValue}
      accessibilityLabel={de ? 'Versandart' : 'Delivery'}
    >
      <UI.RadioItem
        value="standard"
        label={de ? 'Standardversand' : 'Standard delivery'}
        description={de ? 'Drei bis fünf Tage' : 'Three to five days'}
      />
      <UI.RadioItem value="express" label="Express" />
      <UI.RadioItem
        value="unavailable"
        label={de ? 'Nicht verfügbar' : 'Unavailable'}
        disabled
      />
    </UI.RadioGroup>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <RadioExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

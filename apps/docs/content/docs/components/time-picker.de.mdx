Eine lokale Uhrzeit im 24-Stunden-Format wählen, Minuten außerhalb des Rasters erhalten und eigene Vorgaben liefern. Ein Sheet kann bis zur Bestätigung einen Entwurf halten.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="TimeselectionExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function TimePickerExample({ de = false }: StoryProps) {
  const [time, setTime] = React.useState<string | null>('09:00');
  const t = (en: string, german: string) => (de ? german : en);
  return (
    <View style={{ gap: 16 }}>
      <UI.TimeField
        label={t('Choose time', 'Uhrzeit wählen')}
        emptyLabel={t('No time', 'Keine Uhrzeit')}
        value={time}
        onChange={setTime}
        hourLabel={t('Hour', 'Stunde')}
        minuteLabel={t('Minute', 'Minute')}
        confirmLabel={t('Done', 'Fertig')}
        clearLabel={t('Clear time', 'Uhrzeit entfernen')}
      />
      <UI.TimeGrid
        value={time}
        onChange={setTime}
        hourLabel={t('Hour', 'Stunde')}
        minuteLabel={t('Minute', 'Minute')}
        minuteStep={15}
      />
      <UI.TimeChips
        value={time}
        onChange={setTime}
        options={[
          { value: '09:00', label: t('Morning', 'Morgens') },
          { value: '19:00', label: t('Evening', 'Abends') },
        ]}
      />
      <UI.Text accessibilityLiveRegion="polite">{time ?? '—'}</UI.Text>
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <TimePickerExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `TimeField`, `TimePickerSheet`, `TimeGrid`, `TimeChips`.

Wichtige Props: `value`, `onChange`, `hourLabel`, `minuteLabel`, `minuteStep`, `presets`, `onConfirm`, `onClear`, `material`, `glassStyle`, `tintColor`, `fallbackColor`, `interactive`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

Glas, solide Alternativen und den Hintergrund vergleichen: [Picker und schwebende Materialien](/de/docs/components/overlay-materials).

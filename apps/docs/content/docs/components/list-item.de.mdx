Allgemeine Zeilen mit führendem Inhalt und nachgelagerten Aktionen zusammensetzen.

## Verwendung und Zustände

Ohne `onPress` ist die Zeile ein statischer Container und darf unabhängige Aktionen enthalten. Mit `onPress` ist sie ein Button: führende und nachgelagerte Inhalte dekorativ halten, keine interaktiven Elemente verschachteln. `disabled` sperrt die Zeilenaktion; `selected` ändert Fläche und barrierefreien Zustand. Lange Texte umbrechen. `className` und `style` gelten für die Zeile.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="ListitemExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function ListItemExample({ de = false }: StoryProps) {
  const [selected, setSelected] = React.useState(false);
  return (
    <View>
      <UI.ListItem
        title={de ? 'Projekt' : 'Project'}
        description={de ? 'Zuletzt bearbeitet' : 'Recently edited'}
        leading={<UI.Avatar initials="IS" accessibilityLabel="Isoline" />}
        trailing={<UI.Badge label="3" />}
        selected={selected}
        onPress={() => setSelected(!selected)}
      />
      <UI.ListItem title={de ? 'Nicht verfügbar' : 'Unavailable'} disabled onPress={() => {}} />
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <ListItemExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

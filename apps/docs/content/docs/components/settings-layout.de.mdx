Zurück-Zeile, Titel, scrollender Inhalt mit sicheren Abständen und Overlays außerhalb des Scrollbereichs. Navigation kommt über onBack.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="SettingsscreenlayoutExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function SettingsLayoutExample({ de = false }: StoryProps) {
  const [enabled, setEnabled] = React.useState(true),
    [status, setStatus] = React.useState('');
  const t = (en: string, german: string) => (de ? german : en);
  return (
    <View style={{ minHeight: 360 }}>
      <UI.SettingsScreenLayout
        title={t('Settings', 'Einstellungen')}
        caption={t('A router-free screen layout.', 'Ein Bildschirmrahmen ohne Router.')}
        backLabel={t('Back to examples', 'Zurück zu Beispielen')}
        onBack={() => setStatus(t('Back selected', 'Zurück ausgewählt'))}
      >
        <UI.SettingsSection title={t('Appearance', 'Darstellung')}>
          <UI.SettingsRow
            label={t('Enable option', 'Option aktivieren')}
            value={enabled}
            onValueChange={setEnabled}
            first
          />
          <UI.SettingsRow
            label={t('Details', 'Details')}
            onPress={() => setStatus(t('Details selected', 'Details ausgewählt'))}
          />
        </UI.SettingsSection>
        <UI.Text accessibilityLiveRegion="polite">{status}</UI.Text>
      </UI.SettingsScreenLayout>
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <SettingsLayoutExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `SettingsScreenLayout`, `SettingsRow`.

Wichtige Props: `title`, `caption`, `onBack`, `backLabel`, `children`, `overlay`, `scrollProps`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

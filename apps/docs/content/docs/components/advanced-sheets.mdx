title: 'Forms and scrolling in sheets'
description: 'Keep inputs reachable and lists scrollable.'
---

Use `PanelSheet` for a form displayed inside the current screen. Render it last in a full-height screen, above the content it covers. It follows the animated keyboard height, caps the panel to the remaining space, includes a `SheetScrollView`, and handles Android Back. It needs the app's gesture root and safe-area provider.

```tsx
import * as React from 'react';
import { View } from 'react-native';
import { Button, Input, PanelSheet } from '@isoline-ui/react-native';
export function RenamePanel() {
  const [visible, setVisible] = React.useState(false);
  return (
    <View className="flex-1">
      <Button label="Rename" onPress={() => setVisible(true)} />
      <PanelSheet visible={visible} onClose={() => setVisible(false)}>
        <Input label="Name" placeholder="New name" />
        <Button label="Done" onPress={() => setVisible(false)} />
      </PanelSheet>
    </View>
  );
}
```

`PanelSheet` accepts `visible`, `onClose`, and `children`. If a form must start fresh on every opening, mount a separate form component for each session; keep any draft that must survive closing in the app.

## Scroll a long modal sheet

`BottomSheet` opens a native modal; `PanelSheet` is an inline overlay. For a long list inside a modal, wrap it in `SheetScrollView` and set `BottomSheet.maxHeight`. The list forwards React Native `ScrollViewProps`, including scroll/layout handlers and content-container styling.

```tsx
import { BottomSheet, SheetScrollView, Text } from '@isoline-ui/react-native';
export function LongList({ visible, onClose }: { visible: boolean; onClose: () => void }) {
  return (
    <BottomSheet visible={visible} onClose={onClose} maxHeight="85%">
      <SheetScrollView keyboardShouldPersistTaps="handled" style={{ flexGrow: 0 }}>
        {Array.from({ length: 50 }, (_, index) => (
          <Text key={index}>Item {index + 1}</Text>
        ))}
      </SheetScrollView>
    </BottomSheet>
  );
}
```

## Custom sheet frames

`useSheet(visible, onClose)` returns `mounted`, `panelStyle`, `scrimStyle`, `onPanelLayout`, `pull`, and `scrollContext`. Pass its result as `sheet` to `SheetFrame`, together with `visible`, `onClose`, and `children`. Optional `lift` and `panelStyle` position an inline frame. Use `mounted` to retain the frame until the exit finishes. Keep `useSheetTransition` only for existing custom opening transitions; it does not own the complete lifecycle.

`SheetFrame.dragFrom` overrides the theme's `sheetGesture` (`handle` or `panel`). Whole-panel gestures coordinate with `SheetScrollView`; horizontal content gestures retain their own direction. The width is capped at 640dp. The handle is a real Close button; VoiceOver Escape also closes. Test scroll handoff, cancelled drags, keyboard, rotation, large text and reduced motion on both platforms.

## Material options

Suitable controls and overlay surfaces support the shared material contract, including `glassStyle`, `tintColor`, `fallbackColor`, and `interactive`. See [Materials and Liquid Glass](/en/docs/foundations/materials) for defaults, adapters, states, and fallbacks.

Ein semantischer Aktions-Chip für kurze Aktionen, getrennt von Filterauswahl.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="ActionChipExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function ActionChipExample({ de = false }: StoryProps) {
  const [status, setStatus] = React.useState('');
  const t = (en: string, german: string) => (de ? german : en);
  return (
    <View style={{ gap: 12 }}>
      <UI.ActionChip
        label={t('Add action', 'Aktion hinzufügen')}
        icon={UI.BackIcon}
        tone="primary"
        onPress={() => setStatus(t('Action selected', 'Aktion ausgewählt'))}
      />
      <UI.ActionChip
        label={t('Secondary action', 'Zweite Aktion')}
        tone="tertiary"
        onPress={() => setStatus(t('Secondary selected', 'Zweite ausgewählt'))}
      />
      <UI.ActionChip
        label={t('Disabled action', 'Deaktivierte Aktion')}
        disabled
        onPress={() => {}}
      />
      <UI.Text accessibilityLiveRegion="polite">{status}</UI.Text>
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <ActionChipExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `ActionChip`.

Wichtige Props: `label`, `icon`, `tone`, `onPress`, `disabled`, `material`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

Statische Platzhalter anzeigen, während Inhalte laden.

## Verwendung und Zustände

Mehrere Blöcke passend zum späteren Layout verwenden. Skeletons sind statisch, nicht interaktiv und vor Hilfstechnologien verborgen. Den Ladezustand einmal am umgebenden Bereich mit lokalisiertem Status und Busy-Zustand mitteilen. Nach Erfolg ersetzen, bei Fehler Nachricht und Wiederholen-Aktion zeigen. Breite/Höhe nehmen React-Native-Dimensionen an; `radius` ist in dp.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="SkeletonExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function SkeletonExample({ de = false }: StoryProps) {
  const [loading, setLoading] = React.useState(true);
  return (
    <View style={{ gap: 16 }}>
      <UI.Button
        label={de ? 'Ladezustand wechseln' : 'Toggle loading'}
        onPress={() => setLoading(!loading)}
      />
      <View accessibilityState={{ busy: loading }}>
        {loading ? (
          <View style={{ gap: 12 }}>
            <UI.Text accessibilityLiveRegion="polite">
              {de ? 'Inhalt wird geladen' : 'Loading content'}
            </UI.Text>
            <UI.Skeleton width={64} height={64} radius={32} />
            <UI.Skeleton />
            <UI.Skeleton width="60%" />
          </View>
        ) : (
          <UI.ListItem title={de ? 'Inhalt geladen' : 'Content loaded'} />
        )}
      </View>
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <SkeletonExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

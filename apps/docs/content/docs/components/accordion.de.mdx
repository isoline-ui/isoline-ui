Kontrollierte Inhalte ohne Navigationswechsel aufklappen.

## Verwendung und Zustände

Die App kontrolliert `expanded`. Jede Instanz ist unabhängig; höchstens einen offenen Abschnitt bei Bedarf im Elternteil steuern. Verborgener Inhalt wird standardmäßig ausgehängt. `keepMounted` erhält lokalen Zustand, entfernt geschlossene Inhalte aber aus Layout und Fokusreihenfolge. Der Auslöser meldet geöffnet/deaktiviert. `className` und `style` gelten für die äußere Gruppe.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="AccordionExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function AccordionExample({ de = false }: StoryProps) {
  const [expanded, setExpanded] = React.useState(false);
  return (
    <UI.Accordion
      title={de ? 'Weitere Informationen' : 'More information'}
      expanded={expanded}
      onExpandedChange={setExpanded}
    >
      <UI.Text>
        {de ? 'Dieser Inhalt wird auf Wunsch sichtbar.' : 'This content appears on request.'}
      </UI.Text>
      <UI.Button label={de ? 'Schließen' : 'Collapse'} onPress={() => setExpanded(false)} />
    </UI.Accordion>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <AccordionExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

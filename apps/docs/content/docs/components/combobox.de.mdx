Eine lokale oder asynchron geladene Einfachauswahl durchsuchen.

## Verwendung und Zustände

Für längere Einfachauswahllisten. `null` zeigt den Platzhalter. Lokal werden Optionsbeschriftungen ohne Groß-/Kleinschreibung gefiltert; deaktivierte Treffer sind gesperrt. Das Sheet enthält eine begrenzte virtualisierte Liste. Für Serversuche `query` und `onQueryChange` gemeinsam liefern; `options` enthält dann bereits die Treffer. Die App muss Anfragen verzögern, veraltete Antworten ignorieren oder abbrechen und die ausgewählte Option beim Trefferwechsel behalten. `loading` ersetzt Treffer; `loadingLabel`, `searchLabel` und `emptyLabel` lokalisieren. `error` ist ein Feldfehler, kein automatischer Wiederholungsmechanismus.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="ComboboxExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function ComboboxExample({ de = false }: StoryProps) {
  const [value, setValue] = React.useState<string | null>(null);
  return (
    <UI.Combobox
      value={value}
      onChange={setValue}
      label={de ? 'Land' : 'Country'}
      accessibilityLabel={de ? 'Land auswählen' : 'Choose country'}
      placeholder={de ? 'Bitte auswählen' : 'Select a country'}
      searchLabel={de ? 'Länder suchen' : 'Search countries'}
      emptyLabel={de ? 'Keine Treffer' : 'No results'}
      options={[
        { id: 'de', label: de ? 'Deutschland' : 'Germany' },
        { id: 'fr', label: de ? 'Frankreich' : 'France' },
        { id: 'it', label: de ? 'Italien' : 'Italy' },
        { id: 'unavailable', label: de ? 'Nicht verfügbar' : 'Unavailable', disabled: true },
      ]}
    />
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <ComboboxExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

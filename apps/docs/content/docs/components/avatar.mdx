Present an image, initials and a badge without contact or network dependencies.

## Complete example

The demo and this example use the same implementation. Reuse the existing provider when integrating this into an app.

```tsx title="AvatarExample.tsx"

import * as UI from '@isoline-ui/react-native';

  return (
    <View style={{ flexDirection: 'row', flexWrap: 'wrap', alignItems: 'center', gap: 24 }}>
      <UI.Avatar
```

## API

Public components: `Avatar`.

Key props: `initials`, `source`, `renderImage`, `size`, `accent`, `badge`, `accessibilityLabel`. Exported props types define the full contract. Labels and actions are supplied by the app.

Check large text, disabled states and VoiceOver/TalkBack in the native screen. Browser demos do not replace device tests.

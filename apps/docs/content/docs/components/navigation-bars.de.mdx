Gemeinsame Zurück-Aktionen, Titel und Navigationsaktionen. Routing bleibt Aufgabe der App.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="NavigationbarsExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function FeedbackExample({ de = false }: StoryProps) {
  const [status, setStatus] = React.useState('');
  const t = (en: string, german: string) => (de ? german : en);
  return (
    <View style={{ gap: 16 }}>
      <UI.NavigationBar
        title={t('Library', 'Bibliothek')}
        leading={
          <UI.BackButton
            label={t('Back', 'Zurück')}
            onPress={() => setStatus(t('Back selected', 'Zurück ausgewählt'))}
          />
        }
      />
      <UI.ScreenTitle title={t('Overview', 'Übersicht')} />
      <UI.TopBar
        onBack={() => setStatus(t('Back selected', 'Zurück ausgewählt'))}
        center={<UI.Text>{t('Collection', 'Sammlung')}</UI.Text>}
      />
      <UI.Toolbar>
        <UI.Button
          size="s"
          label={t('Create', 'Erstellen')}
          onPress={() => setStatus(t('Create selected', 'Erstellen ausgewählt'))}
        />
      </UI.Toolbar>
      <View style={{ minHeight: 90 }}>
        <UI.Snackbar
          message={t('Changes saved', 'Änderungen gespeichert')}
          actionLabel={t('Undo', 'Rückgängig')}
          onAction={() => setStatus(t('Undo selected', 'Rückgängig ausgewählt'))}
        />
      </View>
      <UI.Text accessibilityLiveRegion="polite">{status}</UI.Text>
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <FeedbackExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `NavigationBar`, `TopBar`, `BackButton`, `BackIcon`, `ScreenTitle`.

Wichtige Props: `title`, `leading`, `trailing`, `center`, `onBack`, `onPress`, `material`, `floating`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

Glas, solide Alternativen und den Hintergrund vergleichen: [Picker und schwebende Materialien](/de/docs/components/overlay-materials).

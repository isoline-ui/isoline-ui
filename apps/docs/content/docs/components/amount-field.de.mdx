Lokalen Eingabetext von geparsten numerischen Einheiten trennen. Währung, Validierung, Rundung und Speicherung bleiben explizite Entscheidungen der App.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

```tsx title="AmountfieldExample.tsx"
import * as React from 'react';
import { View, ScrollView } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import * as UI from '@isoline-ui/react-native';

type StoryProps = { de?: boolean };

function AmountFieldExample({ de = false }: StoryProps) {
  const [value, setValue] = React.useState(de ? '12,90' : '12.90');
  const [amount, setAmount] = React.useState<number | null>(12.9);
  return (
    <View style={{ gap: 12 }}>
      <UI.AmountField
        label={de ? 'Betrag' : 'Amount'}
        accessibilityLabel={de ? 'Betrag' : 'Amount'}
        value={value}
        onChangeText={setValue}
        onAmountChange={setAmount}
        locale={de ? 'de-DE' : 'en-US'}
        currency="EUR"
      />
      <UI.Text accessibilityLiveRegion="polite">
        {amount === null
          ? de
            ? 'Unvollständiger Betrag'
            : 'Incomplete amount'
          : String(amount)}
      </UI.Text>
    </View>
  );
}

export function Example() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <UI.IsolineProvider theme={UI.themes.violet.light}>
          <AmountFieldExample de={true} />
        </UI.IsolineProvider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## API

Öffentliche Komponenten: `AmountField`.

Wichtige Props: `value`, `onChangeText`, `onAmountChange`, `currency`, `locale`, `label`, `error`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

Bildzoom mit Pinch, Verschieben, Doppeltippen, Schließgeste und zugänglichen Zoom-Aktionen. Ein eigener Bildrenderer ist optional.

## Vollständiges Beispiel

Die Demo und dieses Beispiel verwenden dieselbe Implementierung. In einer bestehenden App verwende den vorhandenen Provider weiter.

type StoryProps = { de?: boolean };

  return (
    <View style={{ height: 380, gap: 12 }}>

## API

Öffentliche Komponenten: `ZoomableImage`.

Wichtige Props: `uri`, `accessibilityLabel`, `maximumScale`, `labels`, `onTap`, `onDismiss`, `renderImage`. Die exportierten Props-Typen enthalten den vollständigen Vertrag. Beschriftungen und Aktionen werden von der App geliefert.

Prüfe große Schrift, deaktivierte Zustände und VoiceOver/TalkBack im nativen Bildschirm. Browser-Demos ersetzen keine Gerätetests.

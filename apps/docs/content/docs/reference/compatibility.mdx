## Dependency combinations

| Expo SDK | React Native | React |
| -------- | ------------ | ----- |
| 57       | 0.86         | 19.2  |
| 58       | 0.88         | 19.3  |

Use native peer versions selected by your SDK. The UI package expects **NativeWind 4 and Tailwind CSS 3**. Do not copy this documentation website's Tailwind 4 setup into your native app.

## Native features

Android system colors need **Android 12+** and the Isoline module in the binary. Native Liquid Glass needs **iOS 26+**, available glass APIs, and a supported app appearance. Otherwise, the supplied brand theme or solid surface is used. Your Expo SDK defines the app's baseline supported OS versions; the glass requirement does not raise the minimum version of every screen.

## Verification

The alpha sources have passed Android Kotlin compilation and a complete iOS simulator showcase build with Xcode 26.6, plus package, declaration, and Metro export checks. Installed release archives were also checked against SDK 57 / React Native 0.86 types and Android autolinking. That SDK 57 check was not a complete native app build.

Before shipping, test your own screens, keyboard behavior, gestures, accessibility, colors, and materials on supported devices.

## Web and Node

Isoline targets React Native and Expo/Metro, including React Native Web with NativeWind. Site previews run the actual components in modern Chromium, Firefox and WebKit. Importing the UI barrel in a plain Node script is unsupported. See [platforms and web setup](/en/docs/foundations/platforms). Native glass, system palettes and haptics still require a supported device.

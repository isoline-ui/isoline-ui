Verwende die nativen Peer-Versionen deines SDK. Das UI-Paket erwartet **NativeWind 4 und Tailwind CSS 3**. Übernimm die Tailwind-4-Einrichtung dieser Dokumentationswebsite nicht in deine native App.

## Native Funktionen

Android-Systemfarben benötigen **Android 12+** und das Isoline-Modul im App-Binary. Natives Liquid Glass benötigt **iOS 26+**, verfügbare Glas-APIs und eine unterstützte App-Darstellung. Andernfalls werden das übergebene Basistheme oder eine undurchsichtige Fläche verwendet. Dein Expo SDK legt die grundlegenden Betriebssystemanforderungen fest. Die Glas-Voraussetzung erhöht nicht die Mindestversion jedes Bildschirms.

## Prüfstand

Die Alpha-Quellen haben Android-Kotlin-Kompilierung und einen vollständigen iOS-Simulator-Build der Showcase-App mit Xcode 26.6 bestanden, zusätzlich zu Paket-, Deklarations- und Metro-Export-Prüfungen. Installierte Release-Archive wurden außerdem gegen SDK-57-/React-Native-0.86-Typen und Android-Autolinking geprüft. Die SDK-57-Prüfung war kein vollständiger nativer App-Build.

Teste vor der Veröffentlichung deine Bildschirme, Tastatur, Gesten, Bedienungshilfen, Farben und Materialien auf unterstützten Geräten.

## Web und Node

Isoline unterstützt React Native und Expo/Metro, einschließlich React Native Web mit NativeWind. Die Vorschauen führen die echten Komponenten in modernen Chromium-, Firefox- und WebKit-Browsern aus. Der Import des UI-Pakets in einem einfachen Node-Skript wird nicht unterstützt. Siehe [Plattformen und Web-Einrichtung](/de/docs/foundations/platforms). Natives Glas, Systempaletten und Haptik benötigen weiterhin ein unterstütztes Gerät.

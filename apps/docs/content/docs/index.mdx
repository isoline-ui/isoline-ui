## What you can use

`@isoline-ui/react-native` contains the shared components, the provider, and three built-in theme families: **Violet**, **Teal**, and **Cyan**, each in light and dark.

Add `@isoline-ui/native` when you want Android Material You colors or iOS Liquid Glass surfaces. It is optional; you can build a complete interface with the UI package alone.

## How to read these docs

Start with **Installation** and **Your first screen** if this is your first visit. Use **Components** while you are building. The **Recipes** show how the pieces work together in forms, settings, and overlays.

All component examples assume that you have completed the root setup, unless the example includes its own provider. Interactive previews run the actual React Native components through React Native Web. To try touch feedback, system palettes, and glass rendering, run the native showcase or your own development build.
